# Site acadêmico — Cássius Henrique Xavier Oliveira

Site estático pessoal para GitHub Pages, com seções de apresentação, pesquisa, ensino, extensão, trajetória e contato/perfis acadêmicos.

## Publicar como site pessoal do GitHub

1. Entre no GitHub e crie um repositório público chamado exatamente `cassiushenrique.github.io`.
2. Envie `index.html`, `README.md` e a pasta `assets` preservando a estrutura.
3. Vá a **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/(root)` e salve.
6. Aguarde o workflow `pages build and deployment` concluir.
7. O endereço esperado será `https://cassiushenrique.github.io/`.

## Estrutura

- `index.html`: conteúdo da página.
- `assets/style.css`: identidade visual e responsividade.
- `assets/script.js`: menu móvel e ano automático.
- `assets/cassius.jpg`: fotografia extraída do currículo Lattes fornecido pelo autor.

## Atualização

O site foi construído sem framework para facilitar alterações diretamente pelo editor do GitHub. Textos e links podem ser modificados em `index.html`; aparência em `assets/style.css`.
